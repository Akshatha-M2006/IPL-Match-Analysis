# IPL-Match-Analysis (Interactive Dashboard Creation using Power BI)
End-to-end IPL data analysis project using Python, SQL, and Power BI to uncover insights on team performance, player statistics, toss impact, and venue-based trends.
Objective:
To analyze IPL match data and uncover insights into team performance, player stats, and venue trends by building an interactive Power BI dashboard.

Dataset Used:

IPL matches dataset (matches.csv)
IPL deliveries dataset (deliveries.csv)

Key Questions / KPIs:

* What is the total number of matches played in the IPL dataset?
* Which team has the highest number of wins?
* How do team win counts compare across different teams?
* How is the toss decision distributed among teams?
* Which teams win the toss most frequently?
* How do total target runs vary across different seasons?
* Which season recorded the highest total target runs?
* How does venue selection impact match outcomes?

 
## Process:

* Collected IPL datasets (`matches.csv`, `deliveries.csv`) from Kaggle
* Performed data cleaning and preprocessing using Python (Pandas)
* Analyzed key metrics such as team wins, toss outcomes, and seasonal trends
* Used basic SQL queries to aggregate and extract insights from the dataset
* Imported processed data into Power BI
* Built interactive dashboard with bar charts, pie charts, line charts, and KPI cards
* Added slicers (season, venue) for dynamic filtering and better user interaction
* Interpreted results to generate insights on team performance, toss impact, and scoring trends

## Project Insights:

* Certain teams consistently dominate in terms of total wins across seasons
* Toss outcome has **minimal impact** on match results (~50%), indicating other factors are more influential
* Seasonal trends show variation in total target runs, reflecting changes in playing conditions and strategies
* Some venues are associated with **higher scoring matches**, indicating pitch conditions favor batting
* Team performance varies based on venue and match conditions

This project demonstrates how data analytics can be used to uncover meaningful patterns in sports data. By analyzing IPL match datasets using Python, SQL, and Power BI, key insights were derived related to team performance, toss impact, and scoring trends. The interactive dashboard enables easy exploration of data and supports data-driven decision making. Overall, the project highlights strong skills in data analysis, visualization, and real-world problem solving.
